# Performance-First Spend Management Dashboard

An advanced frontend capstone that builds a data-dense spend-management dashboard the way a fintech product has to — fast under real load. You render thousands of transactions in a virtualized, filterable, sortable table that stays smooth at 60fps; build the rows on a small in-house design system so every surface is consistent; keep interactions instant with memoization and optimistic updates; and measure the result with the Profiler and Web Vitals so the speed is proven, not assumed. The result shows you can build a beautiful UI that is also performant at scale — not a clean demo that melts at ten thousand rows.

## Stack
- TypeScript
- React
- Vite
